# Release repair: 2026-11-16

This release combines the sales print changes with verified release and form fixes.

- PrimeReact overlays and ripple now respect the operating system's reduced-motion
  preference, including changes while the app is open. A closing calendar overlay
  could otherwise remain at its desktop coordinates after a mobile resize on Linux.
  The Arabic/English invoice-preflight check now also waits for the closed calendar
  to detach before measuring mobile overflow.
- Existing installations receive the delivery-note permission catalog and grants
  for the standard Admin, Sales and Warehouse roles, matching the fresh-install
  seed. Custom roles and existing permissions are preserved.
- Delivery quantities now live in the table row data so memoized cells display
  edits correctly. Displayed defaults, clearing, validation and submitted lines use
  the same values. Browser checks cover two rows, decimals, Arabic/English and all
  four interface styles in light/dark mode, including mobile sizing.
- Active sidebar icons use the theme accent rather than white. The profile menu
  always offers app installation (or installed status), even after dismissing the
  automatic banner, with browser instructions when a native prompt is unavailable.
- Installed-app icons use the black brand tile; versioned icon URLs let browsers
  discover the update. Existing installed shortcuts update on the browser's schedule.

## Database rollout

Back up the target database and verify the backup restores before applying:

1. `20261116090000_sales_goods_delivery_note`
2. `20261116150000_delivery_note_permissions`

The first migration adds delivery records and a delivered quantity to order lines;
the second adds permissions. Neither rewrites posted financial records. Running
the full demo seed is not an upgrade step.

Deploy migrations explicitly using the schema-owner connection before releasing
the API and worker. A successful Railway code build alone does not apply them.
The previous demo release had the code but neither the new tables nor permissions.
